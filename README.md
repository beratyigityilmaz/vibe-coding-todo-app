# Vibe Coding Todo List App

This project is a Todo List web application built using a vibe coding tool.

## Description
This is a modern, frontend-only Todo List application that allows users to manage daily tasks efficiently. The application was built with the help of an AI-powered vibe coding tool (Replit Agent), which assisted throughout the development process.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Persistent data storage using localStorage
- Clean and responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript
- React
- Tailwind CSS

## Vibe Coding Tool Used
- Replit Agent

## Setup and Run Instructions
1. Clone the repository
2. Install dependencies using npm install
3. Run the project with npm run dev
