# Vibe Coding Experience – Todo List App

## Tool Selection Justification
I chose Replit Agent for this project because it provides an AI-powered development environment that is directly integrated into the coding workspace. Unlike traditional AI tools used in separate browser windows, Replit Agent understands the entire project context, allowing it to generate, modify, and debug code efficiently. Its browser-based setup and instant execution made it an ideal choice for building a small but fully functional web application.

## Development Process
During development, I primarily interacted with Replit Agent using natural language prompts. I started by asking the agent to generate a complete Todo List application using HTML, CSS, and JavaScript. After reviewing the initial output, I tested the application and identified small issues such as UI alignment and feature consistency. I then asked the agent to refine the code and improve functionality.

The iterative process was fast and efficient. Each time I requested a change, the agent modified multiple parts of the project when necessary, demonstrating an understanding of how different files and features were connected. This significantly reduced the amount of manual coding required.

## Challenges and Solutions
One of the main challenges was ensuring that all features worked correctly together, especially task persistence using localStorage. In some cases, the AI-generated code required minor manual adjustments to ensure data was saved and loaded properly. Replit Agent helped identify logical issues, but reviewing the code manually was still necessary to confirm correctness.

Another challenge was maintaining clean and readable code. While the AI produced working solutions quickly, some refactoring was required to improve variable naming and structure. Combining AI assistance with human oversight resulted in a more maintainable final project.

## Reflection
This experience showed how vibe coding tools shift the developer’s role from writing every line of code to guiding and refining AI-generated solutions. I was surprised by how effectively Replit Agent understood project-level intent rather than just individual code snippets. This significantly improved development speed and reduced cognitive load.

In the future, I would use vibe coding tools for rapid prototyping and small to medium-sized projects. However, for large-scale or highly critical systems, human-driven design and review would remain essential. Overall, vibe coding represents a powerful evolution in software development workflows.
